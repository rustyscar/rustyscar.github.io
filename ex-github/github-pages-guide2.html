一個免費永久的個人網站

本指南以虛構帳號 oldchang 作為範例。實際操作時把 oldchang 換成你自己的帳號名即可。

  • https://oldchang.github.io/
  • https://oldchang.github.io/your-project/
  • https://oldchang.github.io/another-project/

§ 01申請 GitHub 帳號

如果你已經有 GitHub 帳號,跳到 §02。

  1. 打開 GitHub 官網

    網址:github.com

  2. 點右上角 Sign up

    進入註冊頁面。

  3. 填入 Email

    用一個你常用的信箱,之後驗證、找回密碼都靠它。

  4. 設定密碼

    至少 15 個字元,或 8 字元含數字與字母。建議用密碼管理工具產生。

  5. 選擇 username(帳號名)

    這是本指南最重要的決定。

    關鍵概念
    你選的 username 會永久變成你網址的一部分,例如 oldchang.github.io。改名要付出代價(舊網址全死),所以一次選好。

    建議:

    · 全小寫

    · 不含底線或特殊符號(連字號 - 可以)

    · 短一點好記

    · 確認你不會討厭自己未來名片印上這個名字

    本指南範例假設你的 username 是 oldchang。

  6. 通過圖形驗證

    依指示完成(通常是辨識圖案)。

  7. 驗證 Email

    GitHub 會寄一封驗證信到你剛填的 email。打開信件,點裡面的連結或輸入驗證碼。

  8. 完成註冊

    後續可能會問你的角色、興趣等,可以全部跳過(Skip personalization)。

§ 02建立 repo(關鍵命名)

repo(repository)是 GitHub 上的「專案資料夾」。我們要建一個結構特殊的 repo,讓網址最乾淨。

為什麼命名很關鍵
GitHub 的規則:如果 repo 名字跟 username 完全一樣(例:oldchang.github.io),這個 repo 會直接掛在根網址,不會多一層路徑。每個帳號只有一次機會用這個特殊命名。
  1. 點右上角 + 圖示

    下拉選單選 New repository。

  2. Repository name 必須打: 
    oldchang.github.io
    注意: 把 oldchang 換成你自己的 username。格式永遠是 你的username.github.io,後面那個 .github.io 是固定的,一字不能差。
  3. Description(描述)可空

    之後再改也行。

  4. 必須選 Public

    GitHub Pages 免費版只支援 Public repo。Private repo 需付費。

  5. 勾選 Add a README file

    這樣 repo 不會是空的,Pages 才會啟動。

  6. 點綠色 Create repository 按鈕

    創建完成,你會被帶到 repo 主頁。

§ 03啟用 GitHub Pages

用 username.github.io 這種特殊 repo,通常 Pages 會自動啟用,但還是確認一次。

  1. repo 上方點 Settings

    注意是 repo 的 Settings,不是帳號的 Settings。

  2. 左側選單找 Pages

    在「Code and automation」分類下。

  3. 確認設定

    · Source:Deploy from a branch

    · Branch:main

    · 資料夾:/ (root)

    如果跟上面不一樣,改成這樣然後點 Save。

  4. 等候啟用

    幾秒到 1 分鐘後,頁面上方會出現綠色框:

    Your site is live at https://oldchang.github.io/

    看到這個就代表 Pages 已啟用。

§ 04上傳第一個 HTML 檔

把你的網頁檔放到對應位置,網址才會看得到內容。

資料夾結構邏輯
把每個專案放在不同子資料夾裡,網址就會用資料夾名稱來分類。例如 myproject/index.html → 網址 oldchang.github.io/myproject/。
  1. 本機準備 HTML 檔

    檔名必須是 index.html(全小寫)。每個資料夾的主頁都叫這個名字,網址才能省略檔名。

    Windows 記事本陷阱: 存檔時「存檔類型」要選「所有檔案 (*.*)」,否則會被存成 index.html.txt。
  2. 回到 repo 主頁

    點上方 repo 名稱(oldchang.github.io)回到主頁。

  3. 點 Add file → Upload files

    位置在檔案列表的上方,綠色 Code 按鈕旁邊。

  4. 拖檔案進虛線框

    或點 choose your files 用對話框選檔。

  5. 改檔名,加上資料夾路徑 (關鍵步驟)

    上傳完成後,列出的 index.html 旁邊有個輸入欄位。點一下,改成:

    myproject/index.html

    中間那個斜線就是「自動建立 myproject 資料夾」的指令。myproject 換成你想要的名字。

    名字規則: 全小寫、不含空格、不含中文。連字號 - 可以。例:trip-2026、portfolio、blog。
  6. 填寫 Commit message

    頁面下方有兩個欄位。第一個填修改說明(隨便寫,例:Add first page)。

  7. 點綠色 Commit changes 按鈕

    送出後,GitHub 會開始部署。

§ 05訪問你的網站

  1. 等部署完成

    commit 後通常 1–3 分鐘。要看狀態,repo 上方點 Actions 頁籤,看最新一筆有沒有綠色勾(✓)。

  2. 打開瀏覽器

    網址(範例):

    https://oldchang.github.io/myproject/

    看到你上傳的網頁內容,完成。

  3. 看不到變化?

    常見原因:瀏覽器快取。按 Ctrl + Shift + R(Mac:Cmd + Shift + R)強制清除快取重新整理。

§ 06關鍵注意事項

踩過會痛,看完省事。

Public only
免費版只能用 Public repo。所有檔案內容公開,別放任何密碼、API 金鑰、私人資料。
禁止商業用途
違反 GitHub TOS。個人專案、作品集、開源、學習都 OK,商業用途要換 Cloudflare Pages 或付費方案。
大小寫敏感
資料夾、檔名、網址通通要全小寫。MyProject 跟 myproject 是不同的東西。
主頁檔名
每個資料夾的主頁必須叫 index.html。檔名打錯網址會 404。
username 是永久的
改 username 會牽動所有網址、所有設定。建議一次選好,不要事後改。
頻寬上限
100GB/月。一般個人網站絕對用不到,除非爆紅或被攻擊。

§ 07之後要更新

建好之後,日常維護就這兩招。

  1. 小修改(改幾行字)

    進入對應資料夾 → 點 index.html → 右上角鉛筆圖示 ✏️ → 線上編輯 → 拉到下方 Commit changes。

  2. 整個檔案換掉

    進入資料夾 → 點 index.html → 右上角 ... → Delete file → Commit。回資料夾 → Upload files → 上傳新檔 → 改名為 index.html → Commit。

  3. 新增另一個專案

    跟 §04 一樣的流程,只是檔名改成新資料夾,例如 blog/index.html、portfolio/index.html。

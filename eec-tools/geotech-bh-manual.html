安裝說明

每台電腦只需設定一次

這是什麼

Geotech_BH 是一支在本機執行的小工具:輸入地址,自動上網查詢鄰近的地質鑽孔, 算出各孔相對基地的方位角與距離,並產生位置關係圖(PNG)與原始柱狀圖。 全程不需要 AI、不需要寫程式,只要點 .bat。

這個資料夾可以整個複製到任何一台 Windows 電腦使用;在新電腦只要先執行一次「安裝.bat」即可。

安裝步驟(每台電腦只需一次)

  1. 解壓縮
    把 Geotech_BH.zip 解壓縮到任一資料夾(例如桌面)。
  2. 執行安裝
    進入 Geotech_BH 資料夾,點兩下 安裝.bat。
  3. 等待自動完成
    安裝程式會自己判斷環境並補齊缺的東西(見下),需要網路。
  4. 看到 Install complete 即完成
    之後就不必再安裝。

安裝.bat 會自動做的三件事

步驟動作說明
1. 偵測 Python沒有就自動下載官方安裝程式並靜默安裝已安裝 Python 3.10+ 會直接沿用
2. 安裝套件playwright、pillow、python-pptx已安裝會略過
3. 下載瀏覽器抓孔用的 Chromium(約 150MB)這台之前已裝過會自動偵測、直接略過,不重複下載

疑難排解

狀況處理方式
顯示「Python still not found after install」請重新開機後再點一次 安裝.bat。
Python 下載失敗檢查網路/Proxy,或自行到 python.org 安裝 Python 3.12 後再執行 安裝.bat。
Chromium 下載失敗稍後重新執行 安裝.bat 即可(畫圖功能不受影響)。
公司網路限制下載需可連到 python.org 與 playwright 的下載點;必要時請 IT 開放或改用個人網路安裝一次。

搬到另一台電腦

把整個 Geotech_BH 資料夾複製過去,在新電腦先點一次 安裝.bat(它會自動補齊該台缺的 Python / 套件 / 瀏覽器)。裝過一次之後,日後直接點 抓孔出圖.bat 即可,抓孔時要有網路。

②

使用說明

以「台北市羅斯福路三段76號 · 半徑 200 m · 8 孔」為例

一分鐘上手

進入 Geotech_BH 資料夾,點兩下 抓孔出圖.bat,依畫面提示輸入 地址 → 半徑 → 孔數,程式就會自動抓孔、出圖,完成後自動打開結果資料夾。

下面以 台北市羅斯福路三段76號、半徑 200 m、8 孔 為例完整示範。

步驟一:輸入三個問題

點兩下 抓孔出圖.bat 後,會依序問三件事(直接按 Enter 用預設值):

抓孔出圖.bat
請輸入地址 (例: 台北市羅斯福路三段76號): 台北市羅斯福路三段76號
查詢半徑(公尺,直接按 Enter 用 300): 200
最多抓幾孔 (1-16,直接按 Enter 用 8): 8
問題意義預設
地址以此地址為基地中心,向四周找鑽孔必填
查詢半徑搜尋範圍(公尺);範圍內查無孔會自動放寬並顯示300 m
最多孔數抓幾孔(1–16);先取 8 方向代表孔,再由近到遠補滿8 孔

名詞與規則速查

項目說明
方位角正北 0°、正東 90°、正南 180°、正西 270°(順時針)
A/B/C 編號位置圖把點位依距離由近到遠重編號,方便溝通;對照表可查回原孔號
孔數選取≤8:取最近的 N 孔且兼顧八方位分散;>8:八方位代表孔再補最近孔到 N(上限 16)
圖面範圍依最遠孔往上取級距,不會硬拉到搜尋半徑(例:最遠 125 m → 範圍 200 m)

地質鑽探分析工具

工程地質探勘資料庫 · 鑽孔柱狀圖自動判讀與簡報產生　|　v5.0（無 MCP，純本機執行）

① 如何安裝
② 如何使用 & 結果呈現

標準安裝（第一次使用）

適用任何已安裝 Claude Code 的新電腦。需要網路（首次會下載瀏覽器）。

1
確認已安裝 Python 3.10–3.13。沒有的話到 python.org/downloads 安裝，安裝時務必勾選 “Add python.exe to PATH”。
2
將 geotech_v5.0.zip 解壓縮到任意位置。
3
雙擊 install.bat。它會自動：
  • 安裝 Python 套件：playwright、pillow、python-pptx
  • 下載 Chromium 瀏覽器（約 150 MB，一次性）
  • 把程式部署到 C:\Users\你的帳號\Documents\Geotech
4
看到 “Install complete” 即完成。
5
用 Claude Code 開啟資料夾 C:\Users\你的帳號\Documents\Geotech，輸入 /geotech 測試。

升級（已安裝過的電腦）

直接重新執行新版的 install.bat 即可覆蓋更新； 你的 output\ 結果不受影響（安裝程式不會刪除）。

離線安裝（選用，無網路環境）

在有網路的機器先執行一次安裝（會把 Chromium 下載到使用者快取）， 再把以下兩者一起複製到離線機器的相同位置：

  • 整個 Documents\Geotech 資料夾
  • Playwright 瀏覽器快取：C:\Users\你的帳號\AppData\Local\ms-playwright

並在離線機器以 pip install 的離線 wheel 安裝三個套件。

安裝疑難排解

症狀原因 / 解法
install.bat 顯示 Python not found未裝 Python 或未加入 PATH。重裝 Python 並勾選 “Add to PATH”。
pip install 失敗網路 / 代理問題。連上網路或設定 proxy 後重跑 install.bat。
Chromium 下載失敗重跑：py -3 -m playwright install chromium。
/geotech 沒反應確認用 Claude Code 開的是 Documents\Geotech 這個資料夾（技能在其 .claude\skills 內）。
產簡報報錯確認 bin\簡報範本.pptx 存在；--render 需本機有 PowerPoint（沒有則自動略過，簡報仍會產生）。

方式 A（最推薦）— 輸入單觸發

1
用 Claude Code 開啟 Documents\Geotech，輸入 /geotech。
2
它會跳出輸入單，填好四個欄位： 
地址(必填,需完整地址)：台北市中正區羅斯福路76號
半徑(預設200m)：300
孔數(預設8孔,0=不限取8方向)：0
簡報(預設否,填「是」才產簡報)：是
（也可以先編輯資料夾內的 geotech_input.txt 存檔，再說「跑」。）
3
送出後它會自動跑完整流程並回報每階段計時。
背後實際執行（你不用記，技能會做）： 
py bin\geotech_run.py archive --root output --label <舊日期_地址>
py bin\geotech_cli.py  fetch --address "..." --radius 300 --max-holes 0 --compress color256
py bin\geotech_run.py  build  --task task.json --render

方式 B — 直接對話

不用輸入單，直接打：「用 geotech 查 台北市中正區羅斯福路76號，半徑300，8孔，要簡報」。 技能會解析後執行相同流程。

流程說明

  1. 封存：把上一次的結果搬進 output\OLD\日期_地址\，外面只留這一次。
  2. 查孔 + 抓圖：查 8 方位代表孔，全部孔都下載柱狀圖到 output\地址_日期\charts\。
  3. 判讀：最深孔整孔讀（承載層在最底，不可跳頁）＋對照孔看表層（液化關鍵）；其餘孔只用基本資料。
  4. 簡報：只有「簡報＝是」才產出 4 頁 PPT。

結果呈現

孔位資料表（一定會有）

孔號 / 方位 / 距離 / 深度 / 高程 / 柱狀圖頁數。

柱狀圖原圖

每孔 PNG 存在 output\地址_日期\charts\，可直接開啟、稽核、當附錄。

4 頁簡報（選用，4:3 藍色系，微軟正黑體）

頁內容
壹鑽孔位置圖（基地置中、各孔依方位距離擺放）＋ 鑽孔資料表
貳土層綜合剖面（兩代表孔並排、彩色分層、承載層標註，深度軸自動縮放）
參代表孔真實柱狀圖（原圖直接嵌入，不重繪）
肆鑽孔資料總表 ＋ 土層判讀（液化潛勢、承載層、基礎建議）

輸出檔：output\地址_鄰近鑽孔簡報.pptx； 若本機有 PowerPoint，--render 會另存每頁 PNG 於 render\ 供目視檢查。

提醒：本工具為初步參考，最終設計請依原始鑽探報告正本並由負責技師覆核。 半徑內某方位可能無孔，孔數少於指定值屬正常。

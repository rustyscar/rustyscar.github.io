Geotechnical Analysis · MCP v4.11

鑽探地質分析系統
使用說明

輸入一個地址，自動取得鄰近歷史鑽探資料、柱狀圖與試驗數據，由 AI 判讀土層並產出地質分析報告。

版本 v4.11 環境 Claude Desktop + MCP 平台 Windows 資料源 中央地質調查所
1

這是什麼

在 Claude Desktop 裡輸入一個地址，系統會自動完成以下工作：

  1. 找出該地址附近 200m 內的歷史鑽探資料
  2. 取得各鑽孔的柱狀圖（PNG 圖片）
  3. 取得各鑽孔的實驗室試驗資料（USCS、含水量、液塑性限度等）
  4. 由 AI 判讀土層，產出地質分析報告

資料來源：經濟部中央地質調查所公開資料庫。不需要帳號、不需要付費。

3

安裝步驟

解壓縮 → 雙擊 install.bat → 等 2–5 分鐘 → 重開 Claude Desktop → 完成

就這麼簡單。安裝程式會自動處理以下 5 件事：

  • 檢查 Python（沒裝會停下來，顯示下載連結）
  • 安裝相依套件 pip install fastmcp playwright
  • 安裝瀏覽器引擎 playwright install chromium（約 150MB）
  • 複製 Server 到 %USERPROFILE%\geotech_mcp\
  • 寫入 Claude Desktop 設定（會先備份，不覆蓋你既有的設定）
裝完務必「完全關閉」再重開 Claude Desktop（連右下角系統匣的圖示也要關，右鍵 Quit；按 ✕ 不算），MCP 連線才會生效。重開後即可直接使用，不需要其他設定。觸發規則、強制詢問簡報、報告模板都已內建在工具裡。
官網版與 Microsoft Store 版都支援。安裝程式會自動把設定寫到兩個位置（官網版的 %APPDATA%\Claude\ 與 Store 版沙盒的 Packages\Claude*\LocalCache\），不論你的 Claude Desktop 是哪種裝法都能用。雙擊若閃退，改用 cmd 執行（開 cmd → 把 install.bat 拖進去 → Enter）。

（選用）建立 Claude Project 加強規則遵循

這步不是必須的，裝完就能用。若希望 Claude 更穩定遵守規則（例如每次都記得先問要不要簡報），可額外建 Project：上傳 input_format.md 與 report_template.md 到 Project 知識庫，自訂指令填「請嚴格遵循 input_format.md 的規則」。一般使用直接用即可。

4

使用方式

在 Claude Desktop 開一個新對話，輸入觸發詞加地址即可。最簡單的用法：

最小範例
<地質分析> 地址：台北市大安區永康街31巷10號

加上更多選項：

完整範例
【地質分析】 地址：台北市中山區松江路 131 巷 5 弄 3 號 半徑：500m 案名：松江大樓新建工程 備註：考慮 B3 開挖，請特別標註 15m 深度內的軟弱層

欄位說明

欄位必填預設說明
地址✓—台灣地址或 WGS84 座標（如 25.0578, 121.5436）
半徑—200m搜尋範圍，找不到自動擴大至 500m → 1000m
案名—無顯示在報告封面
備註—無任何特殊需求

觸發詞（四種寫法擇一，沒寫觸發詞 Claude 不會啟動分析）

<地質分析> 【地質分析】 [地質分析] "地質分析"
會先問你要不要做簡報：資料抓取與判讀完成後，Claude 會先回報資料摘要，然後主動問你「是否需要製作 PPT 簡報」。回「要」才會產出 6 張投影片報告；回「不用」就停在資料摘要。若想跳過詢問，可在備註寫「直接做簡報」。

常見問題

附帶兩個排查工具：diagnose.bat 一鍵檢查 Python／套件／Chromium／server／設定檔六個環節（跑完截圖給管理員）；repair_config.bat 只重寫 Claude 設定（官網版＋Store 版位置都寫），比重跑 install.bat 快。
設定 → Developer 看不到 geotech / MCP 沒連上
依序試：① 確認「完全關閉」再重開（系統匣右鍵 Quit，不是按 ✕）② 跑 repair_config.bat 再完全重啟 ③ 還是不行就跑 diagnose.bat 截圖給管理員。
Claude 說「找不到工具」或「MCP server 未連線」
完全關閉 Claude Desktop（右下角系統匣也要關），重新開啟。
搜尋很久沒有回應
正常。系統需啟動 Chromium 去政府網站抓資料，第一次較慢（30–60 秒）。超過 2 分鐘無回應，可能是政府網站暫時無法連線，稍後再試。
顯示「no boreholes found」
該地址附近 1000m 內無歷史鑽探資料。可確認地址是否正確、手動指定更大半徑（如 半徑：2000m）、或改用座標輸入。
需要更新 Server
收到新版 geotech_mcp_server.py 後，再跑一次 install.bat 即可覆蓋更新。
7

手動設定（安裝失敗時備用）

如果 install.bat 自動設定失敗，可手動完成四步：

① 安裝 Python 套件（開啟 CMD 輸入）

pip install fastmcp playwright playwright install chromium

② 放置 Server 檔案

C:\Users\<你的使用者名稱>\geotech_mcp\geotech_mcp_server.py

③ 設定 Claude Desktop（編輯下列檔案，不存在就新建）

C:\Users\<你的使用者名稱>\AppData\Roaming\Claude\claude_desktop_config.json

用記事本打開，填入以下內容（記得把 <你的使用者名稱> 換成你的 Windows 帳號）：

{ "mcpServers": { "geotech": { "command": "python", "args": ["C:\\Users\\<你的使用者名稱>\\geotech_mcp\\geotech_mcp_server.py"] } } }

④ 重啟 Claude Desktop（完全關閉包括系統匣，再開啟）

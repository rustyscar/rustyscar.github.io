地質鑽探分析工具

工程地質探勘資料庫 · 鑽孔柱狀圖自動判讀與簡報產生
使用說明　·　版本 v4.18

① 如何安裝

本工具以 MCP Server 形式掛載於 Claude Desktop。 安裝程式會自動完成所有設定，你只需要雙擊一個檔案。

安裝前提：電腦需已安裝 Claude Desktop。桌面版（官網下載）或 Microsoft Store 沙盒版皆可——安裝程式會自動偵測兩種情境並寫入正確位置。 若尚未安裝 Claude Desktop，請先至 Anthropic 官網下載安裝。

標準安裝（第一次使用）

1解壓縮

將整個 geotech_v4.18 資料夾解壓到任意位置（例如桌面或 D 槽）。 請保持資料夾完整，不要單獨搬移其中檔案。

2雙擊 install.bat

直接雙擊資料夾內的 install.bat。會跳出一個黑色命令視窗開始安裝， 過程中請勿關閉。

3自動安裝（共 5 步）

安裝程式會依序自動完成：

  • [1/5] 檢查 Python：電腦若無 Python，會自動從官網下載並靜默安裝 （此步需連網，約下載 25MB）。
  • [2/5] 安裝套件：fastmcp、playwright、Pillow（影像壓縮用）。
  • [3/5] 安裝瀏覽器引擎：Chromium，約 150MB（資料庫抓取需要）。
  • [4/5] 複製伺服器程式到安裝目錄。
  • [5/5] 設定 Claude Desktop：自動寫入連線設定（桌面版＋沙盒版都寫）。
4重啟 Claude Desktop

看到 INSTALL COMPLETE v4.18 後， 完全關閉並重新開啟 Claude Desktop。注意：不是只關視窗—— 右下角系統匣（時鐘旁）的 Claude 圖示也要按右鍵結束，再重開，工具才會載入。

5完成

在對話框輸入含地址的查詢，或輸入關鍵字 <地質鑽探調查> 叫出輸入單即可開始（詳見分頁②）。

升級（已安裝過的電腦）

要更新到新版時，做法完全一樣——雙擊同一個 install.bat。 程式會自動判斷電腦已裝過，切換成「升級模式」：

  • 自動偵測你目前 server 的實際安裝位置（即使裝在 D 槽等非預設路徑， 也會讀 Claude 設定檔找到正確位置去更新，不會更新到錯地方）。
  • 只替換伺服器程式，不重裝 Python／套件／Chromium，速度快。
  • 替換前自動備份舊版，替換後自動驗證語法，失敗會自動還原。
升級後同樣要完全重啟 Claude Desktop（含系統匣圖示）才生效。

離線安裝（選用，無網路環境）

若安裝電腦無法連網，可改為完全離線安裝：

  1. 於有網路的電腦至 python.org 下載 python-3.12.x-amd64.exe。
  2. 改名為 python-installer.exe，放進本資料夾（與 install.bat 同層）。
  3. 再雙擊 install.bat，它會優先使用本地安裝檔，不再連網。

安裝疑難排解

狀況處理方式
工具沒出現／查詢沒反應 多半是 Claude Desktop 沒完全重啟。關閉所有視窗 → 系統匣 Claude 圖示右鍵結束 →（保險）工作管理員結束殘留的 Claude 與 python.exe → 重開。
install.bat 一閃就關 本版已修正編碼問題，正常會停在「Press any key」。若仍異常， 開 cmd，把 install.bat 拖進視窗按 Enter，錯誤訊息會留在畫面。
更新後想還原舊版 安裝目錄內有自動備份檔 geotech_mcp_server.py.backup_*， 複製覆蓋回 geotech_mcp_server.py 再重啟即可。
Python 下載失敗 檢查網路，或改用上方「離線安裝」放入 python-installer.exe。

② 如何使用 & 結果呈現

方式 A（最推薦）：用關鍵字叫出標準輸入單

在對話框輸入這個關鍵字（務必含角括號）：

<地質鑽探調查>

系統會回覆一張「標準輸入單」讓你複製：

--------------------------------------------
地址(必填，需完整地址)：
半徑(預設200m)：
孔數(預設8孔)：
簡報(預設否)：
--------------------------------------------

把它貼回對話框、填好四欄、直接送出，系統就會開始查詢。各欄規則：

欄位必填不填時的預設 / 說明
地址必填不可空白，需完整地址（縣市＋區＋路＋號）。
半徑選填預設 200m。郊區鑽孔稀疏時可填 500 或 1000；找不到時系統會自動擴大。
孔數選填預設 8 孔（8 個方位各取代表孔）；想精簡可填數字（例 4），只取最近 N 孔。
簡報選填預設 否（只給資料表格）。要產生 PPT 簡報才填「是」。

方式 B：直接用一句話講

不想用輸入單，也可以直接描述。地址是唯一必要資訊，其餘用講的補：

查 臺北市中正區南海路35號 的地質鑽探資料

常見講法對照：

你想做的事怎麼說
標準查詢（8 孔、附圖）查 ○○路○號 的鑽孔資料
擴大搜尋範圍查 ○○路○號，半徑 1000 公尺
只要最近幾孔查 ○○路○號，最多 4 孔
含實驗室試驗資料查 ○○路○號，含試驗資料
直接做簡報（不再詢問）查 ○○路○號，直接做成簡報
要 CSV 表格查 ○○路○號，土層表給我一份 CSV

結果呈現

查詢完成後，系統的輸出依序如下。

一定會輸出：鑽孔資料表格

不論任何查詢，系統至少會以表格呈現找到的各孔資料，欄位包含：

孔號方位距離(m)深度(m)地表高程(m)柱狀圖頁數
BL01-1S5420.06.201
WA-2E11940.06.302
BH-1SE12050.06.623

（上為格式示意，實際內容依查詢結果。）

接著：土層初步判讀

系統會判讀各孔柱狀圖，整理土層分布（由淺至深的土層構成、SPT-N 值或範圍、 軟硬程度、地下水位概況）。N 值精度說明見下方。

視需要：PPT 簡報（4 頁，無封面）

當輸入單「簡報」填「是」、或明確要求製作簡報時，系統會產生簡報，內容含：

  1. 鑽孔位置與基地水平關係：基地置中，各孔依方位與距離標示， 實心點＝有柱狀圖、空心點＝無；附半徑圈、指北針、比例尺與鑽孔清單表。
  2. 土層綜合剖面：代表孔並排，依土層上色分層（回填／砂／黏土／卵礫石）， 標註各層描述與 N 值，承載層跨孔連線。
  3. 代表孔柱狀圖：直接嵌入真實柱狀圖原圖，不重繪。
  4. 資料總表與判讀：鑽孔總表＋土層分布判讀重點。

簡報為 4:3 藍色系 微軟正黑體，左下角含公司 LOGO（母片）。

視需要：CSV 檔

要求「給 CSV」時，系統會把孔位表或土層表整理成 CSV 檔供下載，方便匯入 Excel 或後續分析。

關於柱狀圖的清晰度（重要）

為了讓多孔資料能一次傳完（不受單次 1MB 上限影響），柱狀圖預設轉為 單色壓縮版。實測土層描述、SPT-N 值、土壤分類、顏色欄皆清晰可判讀； 唯一會糊掉的是水位「日期」小字（不影響判讀，水位高度在表頭仍可讀）。

若某張圖需要看得更清楚，可直接說「這孔改用彩色版重抓」，即可取得 彩色 256 色版本（檔案較大、容錯較高）。

關於 N 值的精度（誠實說明）

情況呈現方式
距場址最近的代表孔 逐筆精讀，N 值為直接讀出的精確值。
其餘多數孔 可靠讀出土層分層，但單色圖上部分小字數字辨識有限， N 值多以範圍表示（趨勢值）。
工程提醒：N 值是液化分析、承載力計算的關鍵輸入。若需逐筆精確 N 值， 建議對要使用的孔（尤其最深孔）改抓彩色版重新判讀，不要直接採用範圍值做設計。 本工具輸出僅供初步參考，最終設計請由負責技師覆核。

真實生成簡報時的計算原則

製作位置圖與剖面圖時，系統依內建規範進行實際計算而非目測擺放：

  • 位置圖：以基地座標為原點，將各孔座標統一座標系統後 （TW67／TW97 須正式轉換，不可用近似平移），計算相對方位與距離， 並與資料庫值交叉驗證；誤差過大會停下檢查，不硬畫。
  • 剖面圖：各孔共用深度比例尺，層厚等比例對應深度，依層位上色並附圖例。

第一章　總則第1章　総則

1.1　依據

本試驗規範依據下列文件訂定，各文件有衝突時，以較嚴格之規定為準：

  • 建築物耐震設計規範及解說（113年3月修訂版）第九章
  • ASCE 7-22 Chapter 17（參考適用）
  • ISO 22762（參考適用）

1.1　適用根拠

本試験基準は、以下の文書に基づき策定する。各文書間に矛盾が生じた場合は、より厳格な規定を優先して適用する。

  • 建築物耐震設計規範及び解説（113年3月改訂版）第9章
  • ASCE 7-22 Chapter 17（参考適用）
  • ISO 22762（参考適用）

1.2　適用範圍

本規範適用於本工程所採用之全部隔震元件，包含原型試驗（實體試驗）、動態試驗、出廠性能保證試驗及業主出廠抽驗。

1.2　適用範囲

本基準は、本工事に使用する全ての免震部材に適用する。対象となる試験は、原型試験（静的試験）、動的試験、出荷性能確認試験および発注者による抜取検査とする。

1.3　試驗計畫書

廠商須於施工前提交試驗計畫書，經業主書面同意後方可執行試驗。試驗計畫書至少包含：

  • 元件型式說明與行為分類歸屬
  • 試驗分組依據文件（含最大尺寸選定說明）
  • 尺寸效應說明文件
  • 速度依存性分析文件
  • 試驗機構與設備校正證明
  • 試驗時程
  • 動態試驗執行方式（方法一或方法二，詳第四章）
  • 國際型式認證文件（如適用）

1.3　試験計画書

製造者は、施工前に試験計画書を提出し、発注者の書面による承認を得た後に試験を実施する。試験計画書には、少なくとも以下の内容を含めること。

  • 部材の種別および挙動分類の区分
  • 試験グループ分けの根拠資料（最大寸法選定の説明を含む）
  • 寸法効果に関する説明資料
  • 速度依存性分析資料
  • 試験機関および試験機の校正証明書
  • 試験日程
  • 動的試験の実施方法（方法1または方法2、第4章参照）
  • 国際型式認定文書（該当する場合）
第二章　隔震元件分類第2章　免震部材の分類

2.1　行為分類原則

本工程採用之隔震元件，依其復位力來源與阻尼機制分類如下。不同類別之元件力學行為相異，不得互相代表，須分別進行原型試驗。

第一類：橡膠彈性復位／材料內阻尼型　以積層橡膠之彈性變形提供復位力，阻尼由橡膠材料黏彈性提供。第一類A：等效阻尼比 ≤ 10%（NRB）；第一類B：等效阻尼比 > 10%（HDR）。

第二類：橡膠彈性復位／插件塑性阻尼型　復位力來自橡膠彈性變形，阻尼源自金屬插件（如鉛心）之塑性變形（LRB）。

第三類：橡膠彈性復位／滑動摩擦阻尼型　阻尼由內部滑動界面摩擦提供，摩擦係數對速率、壓力、溫度顯著依存。

第四類：曲面幾何復位／滑動摩擦阻尼型　復位力來自曲面重力分量，與軸力及曲率半徑相關，低軸力時復位能力顯著降低（FPS）。

第五類：複合型　併用兩種以上機制，分組歸屬經業主核定。

2.1　挙動に基づく分類

本工事に使用する免震部材は、復元力の発生機構および減衰機構に基づき以下のとおり分類する。異なる分類の部材は相互に代替できず、それぞれ独立して原型試験を実施する。

第1類：積層ゴム弾性復元／材料内部減衰型　復元力は積層ゴムの弾性変形、減衰はゴムの粘弾性による。第1類A：等価減衰定数 ≤ 10%（NRB）；第1類B：> 10%（HDR）。

第2類：積層ゴム弾性復元／プラグ塑性変形減衰型　復元力はゴムの弾性変形、減衰は金属プラグ（鉛プラグ等）の塑性変形による（LRB）。

第3類：積層ゴム弾性復元／摺動摩擦減衰型　減衰は内部摺動界面の摩擦による。摩擦係数は速度・面圧・温度に顕著に依存。

第4類：曲面形状による幾何学的復元／摺動摩擦減衰型　復元力は曲面の重力成分で、鉛直荷重・曲率半径に依存し、低軸力時に復元能力が著しく低下（FPS）。

第5類：複合型　2種以上の機構を併用し、グループ区分は発注者承認による。

2.2　同類別內之分組原則

同類別元件得依下列條件分組，每組以最大尺寸之元件作為試驗代表，並提供尺寸效應說明文件。

第一～三類（積層橡膠系）：

  • 外徑差異 ≤ 25%
  • 橡膠總厚度差異 ≤ 20%
  • 第二類另須：插件／橡膠層截面積比差異 ≤ 10%
  • 第三類另須：滑動面設計摩擦係數差異 ≤ 15%

第四類（曲面幾何復位）：

  • 有效曲率半徑差異 ≤ 10%
  • 設計摩擦係數差異 ≤ 15%（兩條件須同時滿足）

第五類：分組條件由廠商依主要機制提出，經業主書面同意後適用。

2.2　同一分類内の寸法グループ分け

同一分類の部材は以下の条件でグループ分けでき、各グループの試験代表体は最大寸法の部材とし、寸法効果説明資料を提出する。

第1〜3類（積層ゴム系）：

  • 外径の差 ≤ 25%
  • 総ゴム厚さの差 ≤ 20%
  • 第2類の追加：プラグ／積層ゴム断面積比の差 ≤ 10%
  • 第3類の追加：摺動面の設計摩擦係数の差 ≤ 15%

第4類（曲面形状）：

  • 有効曲率半径の差 ≤ 10%
  • 設計摩擦係数の差 ≤ 15%（2条件を同時に満たすこと）

第5類：グループ分け条件は製造者が主要機構に基づき提案し、発注者の書面承認後に適用。

第三章　原型試驗（靜態）第3章　原型試験（静的試験）

3.1　試體數量

每組取最大尺寸之試體至少 2 件。持認證文件者得申請減為 1 件，須：本案規格在認證範圍內、申請載明並經業主同意、仍須進行原型試驗（不得完全替代）。可接受：日本國土交通大臣認定書或同等國際認證。

3.1　試験体数量

各グループから最大寸法の試験体を少なくとも2体用いる。認定保有時は1体への削減を申請可：本工事規格が認定範囲内、申請を明記し発注者承認、原型試験は必須（完全代替不可）。認められる認定：国土交通大臣認定書または同等の国際認定文書。

3.2　試驗依據

試驗依據耐震設計規範 §9.5.2.1（位移與垂直載重條件）執行。

3.2　試験根拠

試験は台湾耐震設計規範 §9.5.2.1（変位および鉛直荷重条件）に準拠して実施する。

3.3.1　垂直載重試驗

試驗條件：由零單調加載至 QD＋½QL＋QE，再卸回零。

結果標準：

  • 試體穩定無明顯破壞
  • 垂直勁度 ≥ 設計值 80%

3.3.1　鉛直荷重試験

試験条件：ゼロから QD＋½QL＋QE まで単調増載し、ゼロまで除荷する。

合否判定：

  • 試験体が安定し、明らかな損傷がないこと
  • 鉛直剛性が設計値の80%以上

3.3.2　常態載重試驗

試驗條件：垂直載重 QD＋QL；側向位移為風力對應位移；20 循環。

結果標準：

  • 第一、二類：切線勁度正值，不得降伏
  • 第三、四類：不得滑動（起動摩擦力 ≥ 設計風力）

3.3.2　常時荷重試験

試験条件：鉛直荷重 QD＋QL；水平変位は風荷重対応変位；20サイクル。

合否判定：

  • 第1・2類：接線剛性が正値、降伏を生じないこと
  • 第3・4類：滑動を生じないこと（起動摩擦力 ≥ 設計風荷重）

3.3.3　不同變形特性試驗

試驗條件：垂直載重 QD；側向位移 100→200→300→400→500→400 mm，各 3 循環（共 18）。

結果標準：

  • 各循環有效勁度與三循環均值差 ≤ ±10%
  • 兩試體均值差 ≤ 10%
  • 末組均值與設計值差 ≤ ±15%
  • 平均等效阻尼比及消能 ≥ 設計值 85%

3.4　試驗地點

試驗地點不限，但試驗機構須提供有效設備校正證明。業主有權見證，廠商須於試驗前至少 14 個工作天通知。

3.4　試験場所

試験場所は限定しないが、試験機関は有効な校正証明書を提出する。発注者は立会権を有し、製造者は試験の少なくとも14執務日前に通知する。

第四章　動態試驗第4章　動的試験

4.1　基本要求

各類元件除靜態原型試驗外，均須提供動態試驗資料，以方法一或方法二擇一執行，並於試驗計畫書載明。

4.1　基本要件

全分類の部材は静的原型試験に加え動的試験資料を提出し、方法1または方法2のいずれかを選択して試験計画書に明記する。

4.2　方法一：本案執行動態試驗（優先）

  • 基準試驗速率：650 mm/s（下限）；不得超過試驗機台水平速度上限（例：NCREE BATS 1,000 mm/s）
  • 試驗位移 ≥ 400 mm
  • 至少兩頻率點，涵蓋 650 mm/s 對應頻率點及其 1/2
  • 每循環記錄最大力、位移、有效勁度、消能、實際速率
  • 實際速率與真實地震速率之差異須以速度相依外推說明（§4.4）

4.2　方法1：本工事における動的試験（優先）

  • 基準試験速度：650 mm/s（下限）；試験機の水平速度上限（例：NCREE BATS 1,000 mm/s）を超えないこと
  • 試験変位 400 mm 以上
  • 少なくとも2点（650 mm/s 対応振動数およびその1/2）
  • 各サイクルで最大力・変位・等価剛性・消費エネルギー・実速度を記録
  • 実速度と真の地震時速度の差異は速度依存性の外挿で報告（§4.4）

4.3　方法二：提交過往動態試驗報告（替代）

廠商無法執行動態試驗時得提交過往報告，須同時滿足：

  • (a) 報告距簽約日 ≤ 3 年
  • (b) 同分類、位移 ≥ 400 mm、軸力為設計軸力 70–130%、速率 ≥ 400 mm/s
  • (c) 每類 ≥ 3 份、≥ 2 批次、≥ 1 份第三方
  • (d) 勁度均值差 ≤ ±15%、偏差 ≤ 20%、阻尼比 ≥ 85%
  • (e) 提交速度依存性分析文件

4.3　方法2：過去の動的試験報告書の提出（代替）

動的試験を実施できない場合、過去報告書で代替可。以下を同時に満足：

  • (a) 契約締結日から3年以内
  • (b) 同分類、変位 400 mm 以上、軸力は設計軸力の70〜130%、速度 400 mm/s 以上
  • (c) 各分類3件以上、2ロット以上、第三者1件以上
  • (d) 等価剛性平均差 ≤ ±15%、偏差 ≤ 20%、減衰定数 ≥ 85%
  • (e) 速度依存性分析資料の提出

4.4　共同要求

  • 實際速率與基準速率（650 mm/s）之比較
  • 若低於真實地震速率，須說明保守性
  • 低估 ≥ 20% 時業主得要求補充動態試驗

4.4　共通要件

  • 実速度と基準速度（650 mm/s）の比較
  • 真の地震時速度を下回る場合は保守性を評価
  • 20%以上の過小評価時、発注者は補完的動的試験を要求可
第五章　出廠性能保證試驗（分流）第5章　出荷前性能確認試験（分類別）

5.1　依據與性質

依 §9.5.5 執行，安裝前必要程序，由廠商安排。各元件依第二章分類適用 §5.4 共同項目與 §5.5 對應分類試驗；不同類別不得互換條件與判準。

5.1　根拠および性質

§9.5.5 に準拠、設置前必須、製造者が手配。各部材は第2章分類に応じ §5.4 共通項目と §5.5 該当分類試験を適用；分類間で条件・判定を置換不可。

5.2　全數試驗原則

全部隔震元件均須於安裝前完成出廠性能保證試驗，不得以任何文件替代。

5.2　全数試験原則

全免震部材は設置前に出荷前性能確認試験を完了；いかなる文書でも代替不可。

5.5　分類性能試驗

位移基準：設計位移 400 mm、最大總位移 600 mm。

5.5.1 橡膠類（1A／B、2）—壓剪組合：條件 QD／400 mm／3 循環／準靜態可。判準：勁度 ±15%、消能／阻尼 ≥ 85%、切線勁度正值、首循記錄但不判準。

5.5.2 滑動・曲面類（3、4）—壓剪滑動：條件 QD／200 mm（½×400）／3 循環／準靜態可＋速度修正。判準：穩定循環 μ（或 Qd）±15%〔待責任技師核定〕、切線勁度正值、首循（含起動）記錄但不判準、第四類殘餘 ≤ 30 mm。

5.5.3 複合類（5）：依主機制比照 5.5.1 或 5.5.2，分流經業主同意。

5.5　分類別性能試験

変位基準：設計変位 400 mm、最大考慮地震変位 600 mm。

5.5.1 積層ゴム類（1A／B・2）—圧縮せん断複合：条件 QD／400 mm／3サイクル／準静的可。判定：剛性 ±15%、消費E／減衰 ≥ 85%、接線剛性正値、第1サイクルは記録するが判定外。

5.5.2 摺動・曲面類（3・4）—圧縮せん断摺動：条件 QD／200 mm（½×400）／3サイクル／準静的可＋速度修正。判定：安定サイクル μ（または Qd）±15%〔責任技師確定〕、接線剛性正値、第1サイクル（起動含む）は記録するが判定外、第4類は残留 ≤ 30 mm。

5.5.3 複合類（5）：主要機構に応じ 5.5.1 または 5.5.2 に準じ、分類は発注者承認。

5.6　滑動類專屬規定

5.6.1 速度修正：速度依存性於原型（動態）階段釘定；出廠允許準靜態，須套用原型導出之速度修正係數換算至地震速率後判定，方法與數值載於計畫書並經審查核定。

5.6.2 磨耗預算：廠商申報滑動界面磨耗（累積容許滑移量）預算；出廠＋原型累積試驗滑移量 ≤ 預算 10%〔待責任技師核定〕，且不得致任一驗收不合格。

5.6　摺動類固有規定

5.6.1 速度修正：速度依存性は原型（動的）段階で確定；出荷前は準静的可だが、原型由来の速度修正係数で地震時速度に換算して判定、方法と数値は計画書に明記し審査承認。

5.6.2 摩耗予算：製造者は摺動界面の摩耗（累積許容すべり量）予算を申告；出荷前＋原型の累積すべり量 ≤ 予算10%〔責任技師確定〕、かついずれの判定も不合格にしないこと。

5.7　試驗記錄

每件元件記錄至少含：編號／型式／尺寸／行為分類、日期地點、載重位移條件、速度模式及實際速率、壓力試驗外觀（含照片）、力—位移曲線、Keff 或 μ／Qd・消能・阻尼比、第三四類速度修正後值與累積滑移量、合格判定。出貨前提交業主存查。

5.7　試験記録

各部材記録に最低：番号／種別／寸法／挙動分類、日時・場所、荷重・変位条件、速度モード・実速度、圧縮試験外観（写真含む）、荷重－変位曲線、Keff または μ／Qd・消費E・減衰定数、第3・4類は速度修正後値と累積すべり量、合否判定。出荷前に発注者へ提出・保管。

5.8　不合格處理

不合格元件不得出貨；查因、提處理方案、經業主同意後重製或修補，並重新進行全數性能保證試驗。

5.8　不合格時の対応

不合格部材は出荷不可；原因究明・対処方案提出、発注者承認後に再製造または補修し、全数の性能確認試験を再実施。
